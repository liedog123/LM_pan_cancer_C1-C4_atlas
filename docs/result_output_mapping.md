# Analysis outputs, publication tables and run order

Updated: 2026-10-03

This map covers **Fig. 1–7 and Supplementary Tables 1–7**, including the Table 3/6 v1.1 increments and all four complete-result companions for Tables 4/6/7. The broader [coverage inventory](figure_coverage.md) remains the scope index. Coverage means a documented source/output relationship, not direct regeneration of every publication field.

The mapping is based on current workflow documentation, output-writing code and recorded publication-table sources. It is not a new execution or numerical comparison. A matching basename indicates a documented source connection, not verified equality of newly generated values. Supplementary tables are selected views of complete analytical results; their displayed rows must not redefine a multiple-testing family.

Entry numbers refer to the linked workflow directory. Output basenames below are relative to each configured output root (or its `results/` subdirectory where specified by the workflow). Every executed entry needs its own independent absent/empty output directory. Matching, legitimately obtained formal intermediates may be used instead of rerunning their producers.

### Table 1 field boundary

The formal source preparation `00_freeze_fig1_source_manifests.R` counts `Cancer × Sample_Type` rows from the matching `full_validation_data`, pivots them to `N_Tumor/N_Normal`, and joins them to the existing median/statistics table. It writes `Fig1C_tumor_normal_statistics_manifest.tsv` without recalculating P values.

Public acid/AG 06 currently does **not** export these count columns. Its two CSVs therefore do not alone reconstruct every `Tumour_normal` field. Use the adopted supplementary worksheet/formal manifest for this prepared-result continuation. If direct generation of all fields from the public entry is later required, a narrowly scoped descriptive-count export would need a separate code change; none was made here.

Table 1 worksheet mapping follows the accepted chapter README and its retained preparation note, together with the public and formal source writers. A standalone current Table 1 workbook exporter was not established in this mapping task. No workbook recreation or cell-by-cell comparison is claimed.
