## How to read the inventory

Three questions are tracked separately, not as mutually exclusive labels:

- **Documented external source:** an accession, publication, provider or release is recorded. Live download availability, the exact local derivative and redistribution rights still need confirmation.
- **Packaged generation route:** an entry can produce a downstream input if its own matching prerequisites are obtained. This is not a claim that a new output equals the study freeze.
- **Author decision or prepared handoff:** the matching study object, reference definition or mapping needs an approved delivery channel, preparation/version information and any necessary provider permission.

A generic TCGA, GEO, GDSC or PRISM download is not interchangeable with a study-prepared matrix or manifest. A DCF placeholder is not an access mechanism. Matching intermediates can be supplied instead of rerunning upstream analyses; this inventory does not require engineering every historical upstream step.

### What closes a route

For each chosen group, record the exact adopted material/version, consuming entry/config field, usable URL/accession or specified access process/provider (or a documented generation route with obtainable prerequisites), allowed contents and any conditions. A planned repository, a local filename or an unnamed contact is not yet an access route. Unknown permissions are not labelled as proven restrictions.
