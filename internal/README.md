# Analysis implementations

The 86 implementation files support 35 manuscript-mapped tasks. Use [run.R](../run.R) and the [task configurations](../tasks), rather than inferring execution order from numeric filenames. E1 and E3 use the same source file in separate step records.

Each implementation has a common purpose/input/output/usage header and retains its methodological comments. Eighty-three scientific bodies are unchanged after stripping the opening comment block. Three scoped extractions are documented in [source checks](../checks/source_scope_check.tsv) and the [reproduction guide](../docs/reproduction_routes.md): survival input preparation, PRISM concordance and shared-axis adjustment. Source results and manuscript scientific content were not changed by this code organisation.
