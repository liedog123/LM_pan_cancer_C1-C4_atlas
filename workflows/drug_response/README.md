# Drug response and programme–feature associations

Entry 01 compares canonical C1 and C4 patients within cancer types and counts significant results across cancers. Predictions indicate candidate vulnerability; they do not establish clinical efficacy.

Copy `config/stage5.paths.example.dcf` to a private `*.local.dcf` file and replace every `SET_ME` placeholder. Paths may be absolute or relative to the configuration file, independent of the shell's working directory. Use an absolute script path when invoking from another directory.

```sh
Rscript /path/to/c1c4_atlas/workflows/drug_response/01_c1c4_from_corrected_predictions.R --help
Rscript /path/to/c1c4_atlas/workflows/drug_response/01_c1c4_from_corrected_predictions.R --config /path/to/stage5.paths.local.dcf --check-config
Rscript /path/to/c1c4_atlas/workflows/drug_response/01_c1c4_from_corrected_predictions.R --config /path/to/stage5.paths.local.dcf
```

The first command reads no configuration or research input. The second reads the DCF configuration and checks filesystem metadata only; it creates no output and runs no statistics. The third runs the full Stage 5 comparison across the 20 matrices. The latter requires a separate, empty or absent output directory. Nonempty output directories and overlap with any configured input are rejected; no overwrite option is available.

The preserved analysis requires at least 30 finite observations per group per drug, uses two-sided Wilcoxon tests (`exact = FALSE`, 95% Hodges–Lehmann confidence intervals), reports Cliff's delta and applies BH to all `ok` drugs within each cancer. Significance requires FDR < 0.05 and |delta| >= 0.20. Lower corrected prediction values indicate greater predicted sensitivity. Cross-cancer summaries count significant cancers without a second BH correction, pooled model or meta-analysis.

Outputs retain version tag `v0.1_20260731` under the configured output directory: `results/00_readiness/` contains inventory, label/conflict audit, matrix audit, coverage, matched-patient manifest and parameters; `results/01_c1c4_drug_response/` contains complete and significant comparisons, cross-cancer counts, candidate tables, QA, summary and session information. These machine-specific outputs can include patient IDs and absolute paths and must remain private. Historical target dimensions are 18 eligible cancers, 286 drugs and 5,148 tested units; they are reference expectations, not a numerical validation of this public copy.

See [input requirements and provenance](../../docs/inputs_and_provenance.md). Statistical rules and all output/QC logic are preserved from the source; the configuration does not expose statistical thresholds as adjustable parameters.
