# AG overall-survival continuation

These four entries continue the original AG1 (High) versus AG3 (Low) clinical analysis from prepared AG clinical objects. They are distinct from the patient-representative C1-C4 Stage 1 workflow. No patient de-duplication, later Stage 1 evaluability thresholds, stage adjustment or cancer-stratified pooled model is introduced.

Run the commands below from this module directory with configured DCF files. Package-root examples are config/ag_km_prepare.paths.example.dcf (00), config/ag_cox.paths.example.dcf (01), config/ag_cox_finalize.paths.example.dcf (02) and config/ag_km.paths.example.dcf (03); copy each outside the input/output directories and replace all paths before use:

0. `Rscript 00_prepare_ag_km.R --config /path/ag_km_prepare.dcf` retains the full source project loop, High/Low selection, survfit/surv_pvalue and raw P < 0.05 display-selection rule. It exports the prepared survival_data_list, significant_projects and each source cancer KM plot; it excludes only the later duplicate significant-cancer assembly.
1. `Rscript 01_run_ag_cox.R --config /path/ag_cox.dcf` fits the original cancer-level models and writes Cox_analysis_results.RData, Cox_warnings.RData and sessionInfo.txt.
2. `Rscript 02_finalize_ag_cox.R --config /path/ag_cox_finalize.dcf` consumes the complete 22-cancer results and frozen cancer-order CSV. It applies the final source BH independently across all cancers within each model type, exports Fig1E_cox_summary_values.csv and the diagnostic Fig1E_cox_model_manifest.tsv, and retains the source summary plots. Its configured source_data_dir is also aliased as source_dir for the retained diagnostic writer. It validates unique result cancer names and complete coverage by the unique frozen order. Its source plot filenames retain historical D naming; current manuscript mapping is Fig. 1E.
3. `Rscript 03_export_formal_ag_km.R --config /path/ag_km.dcf` exports the formal Fig. 1D 12-panel figure-ready tables, source machine checks, session and output manifest. It retains the fixed eleven-cancer display selection and the source assertions for the study freeze.

All entries support `--help` and `--config PATH --check-config`. The check uses file metadata only, returns before loading analysis packages or research objects, and creates no output. Relative paths resolve from the DCF directory. Output must be empty, writable and independent of inputs/configuration.

## Inputs and access

01 requires an Rdata object named projects (the exact source project vector) and an Rdata object named survival_data_list, a cancer-named list of clinical data.frames. Group retains source High/Low labels. Required outcome columns are OS and OS.time; optional source covariates are race, gender and age_at_initial_pathologic_diagnosis. Values/types and row order must match the prepared source object. No public input release has been approved.

00 requires projects and clinical_data_cluster_list named Rdata objects; the clinical list requires Group, OS and OS.time and preserves all additional columns for Cox/pooled export. The prepared list originates from 3.0survival/KM.R, which takes projects and clinical_data_cluster_list, selects High/Low rows and saves the list. The upstream public acid/AG workflow exports clinical_data_cluster_list but is not verified as a replacement for the frozen survival list. Obtain the author-approved prepared list and project object through controlled handoff; alternatively generate them from legitimately obtained clinical inputs using the documented upstream selection, preserving the source project membership, sample rows, Group and outcome/covariate coding. Public 00 retains the source preparation and complete per-project KM loop; its input projects vector must match the supplied clinical list and study scope. No public accession or downloadable prepared object is claimed.

02 requires results_list from 01 or an approved formal intermediate, plus the frozen-order CSV with Cancer column. It refuses an incomplete family rather than adjusting a displayed subset. 03 requires the same prepared list plus all seven fields Group, OS, OS.time, PFI, PFI.time, DSS and DSS.time in every item for the pooled display. These clinical intermediates can contain patient-linked information and are not distributed.

## Preserved methods and output meaning

Univariate Cox uses Group with Low reference. Multivariate models retain available race, gender and age; gender is removed unless MALE and FEMALE occur, with FEMALE reference. Race maps WHITE versus other, including missing/unrecognized values in other; a single level is removed. Age-missing rows are explicitly removed when the column exists; coxph handles remaining model missingness. iter.max is 300. The source projects loop, errors and warning handling are retained. An incomplete model family stops formal finalization; it is not silently reduced. THCA separation/nonfinite intervals and PCPG/PRAD low event counts remain diagnosable through the source extraction.

Final BH comes from 06_make_fig1D_cox_summary.R, not the legacy COX.R single-value adjustment/plot block. KM uses fixed eleven cancers selected in the original analysis by raw log-rank P < 0.05. Within-cancer export requires complete Group/OS/OS.time; pooled OS requires complete values for all seven survival fields and is unadjusted descriptive pooling. The hardcoded counts/P-value checks are retained freeze assertions, not general-purpose acceptance criteria or evidence that this public copy has reproduced them.

The entries perform formal-intermediate continuation and table export, not frozen layout reproduction. Fig. 1D redraw consumes the generated KM plot/summary tables via r01_fig1d_km_12panel_direct_compact.R; Fig. 1E redraw consumes summary/diagnostic tables and order via r01_fig1e_cox_compact.R. Those frozen-layout redraw scripts are mapped but not parameterized/public entries in this module. Manual assembly and current A artwork are separate.
